# Código de conducta

Queremos una comunidad abierta y respetuosa.

- Trata a las demás personas con respeto; critica el código, no a quien lo escribe.
- No se tolera el acoso, la discriminación ni los comentarios ofensivos.
- Acepta la crítica constructiva y explica tus decisiones con evidencia.

Los mantenedores pueden editar o eliminar comentarios, issues y pull requests que incumplan estas normas, y bloquear a quien lo haga de forma reiterada. Para reportar una conducta inapropiada escribe a mg230886@gmail.com.
